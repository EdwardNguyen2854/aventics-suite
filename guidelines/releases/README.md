# Release Guidelines

## Component releases

Components version independently. Do not synchronize component versions for cosmetic consistency.

## Suite releases

A Suite release represents a tested combination of component versions. Planned Suite release naming uses a calendar form such as `2026.10`.

## Channels

Initial channels:

- Development
- Pilot
- Stable

## Compatibility

A Suite release should pin or record the component versions validated together. Components may release independently between Suite releases.
