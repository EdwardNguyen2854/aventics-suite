# Getting Started

Aventics Suite gives engineers one local workspace for Aventics applications, tools, documentation, activity, health, and AI readiness.

## First launch

Open **Aventics Suite** from the Start menu. The desktop app starts or connects to Suite Host automatically. Suite Host then discovers managed components from their `aventics.manifest.json` files.

The Home page shows:

- discovered components;
- current runtime state;
- available tools;
- Skill readiness;
- recent local activity.

## Installed is not the same as running

A component can be installed and healthy even when its host application is closed. For example, Creo Toolkit may show **Installed · Not running** until Creo Parametric starts. This is expected and is not an error.

## Tools

The Tools page is generated from the capability catalog. New managed capabilities appear without hard-coded changes to the page.

## Documentation

Suite documentation is bundled for offline use. Component documentation can be opened from each application card when the component declares a docs path.

## Privacy

Activity tracking stores only operational metadata locally. It can be disabled or cleared under Settings.

## Developer mode

Use **Developer mode** in the sidebar to inspect manifests, capabilities, health, logs, Skills, MCP providers, release compatibility, and diagnostics.
