# User Guide

## Home

Home summarizes installed components, running runtimes, available capabilities, Skill readiness, and frequently used tools.

## Apps

Apps lists discovered managed components. Each card shows version, runtime state, health, capability count, and documentation availability.

## Tools

Tools are grouped by engineering category. Availability reflects component health and runtime state. Safety metadata is visible where relevant.

## AI

AI shows Skills and MCP provider readiness. A provider can be **Unconfigured** without affecting the component's normal UI workflows.

## Activity

Activity contains local metadata such as component ID, capability ID, interface, result, and duration. Engineering payloads are intentionally excluded.

## Updates

The Releases & Updates page compares installed component versions against the versions validated with the current Suite release. Components keep independent version numbers and update mechanisms.

## Settings

Activity tracking and retention are configurable. Development discovery paths remain a developer concern rather than normal user setup.

## Failure behavior

Suite Host failure must not stop Creo, Excel, or other managed engineering applications. Restart Suite to reconnect to the Host if needed.
